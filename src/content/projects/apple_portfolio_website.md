## What it is

![Screenshot of Apple Website - my inspiration](/projects/portfolio_website_v1_4.png)

<figcaption>Something about Apple's website just makes it look so sleek and nice</figcaption>

A portfolio website featuring a 3D self-model inspired by Apple’s website design.

## Why I made it

![A GIF of how I designed my personal website based on Apple's aesthetics](/projects/portfolio_website_v1_6.gif)

<figcaption>The 3D model was built using Three.js</figcaption>

I wanted a visually engaging portfolio that stands out while experimenting with modern web technologies.

## What it does

- Showcases projects and personal information in a sleek, interactive layout
- Displays a 3D model of myself using Three.js
- Provides a visually engaging experience inspired by Apple’s design aesthetics

## Notes

- Creating the 3D model and integrating it with Three.js was more challenging than expected
- Learning a new technology while building the website added a steep learning curve
- Balancing visual appeal with performance required careful optimization
