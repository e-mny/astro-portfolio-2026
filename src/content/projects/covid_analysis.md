## What it is

A beginner data analysis project exploring [COVID-19 datasets](https://www.kaggle.com/datasets/sambelkacem/covid19-algeria-and-world-dataset) using SQL and Python.

## Why I made it

!["Photo at Georgia Tech with fellow Singaporeans"](/projects/GATech.jpg)

<figcaption>SGPxGATech boysss</figcaption>

Came back from exchange at Georgia Tech inspired to finally build something, and COVID had personally impacted my university experience.

## What it does

- Analyzes [COVID-19 datasets](https://www.kaggle.com/datasets/sambelkacem/covid19-algeria-and-world-dataset) across multiple countries
- Tests simple hypotheses (temperature, healthcare capacity, GDP vs outcomes)
- Visualizes trends using basic plots
